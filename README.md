# Black-Box Penetration Testing Exercise: testasp.vulnweb.com

A structured, black-box security assessment of `http://testasp.vulnweb.com` simulating an external attacker methodology. The objective was to map the attack surface, identify vulnerabilities, and pivot through services using sequential tool outputs.

## Methodology & Executive Summary

The assessment followed a 5-phase execution model where the intelligence gathered in each phase directly informed the tactics used in the next.
